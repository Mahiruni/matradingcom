# MA Trading

A clean, mobile-first trading education website for **MA Trading — Learn Trading the Smart Way**.

## Current version
- Premium white / navy / gold visual system
- Responsive navigation
- Hero trading chart visual
- Trading basics, market structure and risk management sections
- Markets overview for Forex, Gold and Crypto
- Roadmap-ready tools section
- About and contact CTA
- No framework or build step required

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Next additions
The structure is intentionally simple so courses, live market data, calculators, trading journal, authentication, member dashboard and additional pages can be added without redesigning the foundation.
